  \begin{itemize}
    \item \textbf{Problem:} Campus coding platforms face security risks from unsafe local code execution, queue bottlenecks during exams, lack real-time scoreboards, and lack automated structural plagiarism checks.
    \item \textbf{Objective 1:} Build hardened Docker container sandboxes with Linux cgroups for deterministic, isolated polyglot evaluation.
    \item \textbf{Objective 2:} Implement asynchronous BullMQ task queues on Redis with $O(\log N)$ real-time ICPC leaderboards and WebSocket updates.
    \item \textbf{Objective 3:} Integrate AST Winnowing plagiarism detection and dual-engine stress testing into a unified developer-friendly interface.
    \item \textbf{Scope:} Contestants, Problem Setters, and Admins; C++20, Python 3.12, Java 21, JS runtimes; Live Contest \& Practice modes.
  \end{itemize}
